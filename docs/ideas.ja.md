# 機能追加の候補（アイデア帳）

2026-11-28、本人が選んだ86個。**候補であって、作ると決めたものではない。** 作るものは1つずつ設計と画面見本を出し、承認をもらってから実装する。

外したもの：透過つき出力、出力の一時フリーズ、黒落ち・ロゴ出し、無音が続いたときの知らせ、返し（会場から会議へ）に足す機能すべて。

## 止まらないための仕組み

- [ ] 音の機器が抜けても、戻ったら自動でつなぎ直す（設計案あり：`docs/auto-recover.ja.md`）
- [ ] 映像の取り込み機器も同じく自動で戻す（設計案あり：`docs/auto-recover.ja.md`）
- [ ] 信号の解像度が変わっても取り込みを自動で再開（設計案あり：`docs/auto-recover.ja.md`）
- [ ] 会議から落ちたら自動で入り直す（設計案あり：`docs/auto-recover.ja.md`）
- [ ] アプリが落ちたら自動で再起動して元の会議に戻る
- [ ] 本番中はWindowsのスリープ・画面オフ・通知を止める
- [ ] 本番ロック（設定を誤って触れなくする）
- [ ] 回線の品質メーター（遅れ・取りこぼし）
- [ ] 本番前の一括チェック（回線・機器・ライセンス・Zoomを順に確認）
