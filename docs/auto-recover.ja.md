# 自動で戻す

2026-11-28。本人の指示「機能追加のアイデア」から、最初に取り上げた4つ（アイデア1〜4）。
同日に本人が承認（画面は見本B）。バージョン0.3.0で実装した。

## 何を足すか
本番中に機器や回線が一度切れても、オペレーターが何もしなくても元に戻るようにする。

| | いま | 足したあと |
|---|---|---|
| 音の出力機器が抜けた | 「機器を選び直してください」で止まる | 同じ名前の機器を探し続け、戻ったら出力を再開 |
| 音の入力機器（Zoomへ送る側）が抜けた | 同上 | 同上 |
| 映像の取り込み機器が抜けた／信号の解像度が変わった | 同上 | 同じ機器で取り込みを再開 |
| 会議から落ちた（回線） | 「失敗」で止まる | 同じ会議に入り直す |

## 決まり
- 戻すのは「オペレーターが選んだもの」だけ。自分で「出さない」「退出」を選んだときは戻さない。
- 機器は**名前**で探す（いまの「前回の機器を覚える」と同じ決まり）。2秒おきに探し、時間の上限はない。別の機器を選ぶか「出さない」にすると探すのをやめる。
- 起動したときに前回の機器が見つからない場合も、同じように探し続ける（あとからつないでも始まる）。
- ASIOは、ドライバーが「設定し直して」と言ってきたときも同じ扱い（止めて、同じ機器で始め直す）。
- 会議に入り直すのは、**回線が原因で落ちたときだけ**。次のときは入り直さない。
  - 主催者が会議を終えた／主催者に外された／無料会議の時間切れ／パスコード違い／会議がない／満員／ロック中
- 入り直しの間隔は 5秒 → 10秒 → 20秒 → 以後30秒。10分たっても入れなければやめて「失敗」にする。「今すぐ試す」「やめる」をいつでも押せる。
- 入り直したあと、枠の割り当ては名前で戻る（いまの「戻ってきた人は同じ枠へ」と同じ決まり）。
- 入り直しは「Zoom接続」の設定でオフにできる（初期値はオン）。機器の自動復帰にスイッチは付けない（オフにしたい場面がないため）。
- 自動更新は、戻している最中も「会議中」と同じ扱いで何もしない。

## 技術
新しい言語・部品は足さない（C++20・Qt Quick のまま。理由：既存の部品の中の話で、外の部品が要らない）。

- `src/core/recovery.*`（新規）：落ちた理由の種類から「入り直す／入り直さない」を決める決まりと、次に試すまでの秒数・あきらめるまでの時間・機器を探す間隔。Zoom・Qt・Windows に依存させず、自動テストを付けた。
- `src/meeting/meeting_client.h`：会議が終わる知らせの直前に「理由の種類」を伝える口を1つ足した（回線／主催者／入れない会議／その他）。Zoomの番号との対応は `src/zoom/` の中だけにある。理由が分からないとき（番号が「なし」「未定義」）は入り直さない。
- `src/app/audio_controller.*`・`return_controller.*`・`meeting_controller.*`：上の部品を使って探す・入り直す。画面には「探しています／入り直し中」の状態を出す。
- 設定ファイル：`zoom.rejoin`（真偽）を1つ足す。無いときはオン。形式の番号（format）は変えない。

## 画面（見本3案）
同じ場面（会議から落ちて2回目の入り直し待ち＋音の機器が抜けて12秒）を3通りで描いた。配色・文字は今の画面のまま。

- **A 上の帯に出す**（`docs/design/recover/opt-a.png`）：いま状態が出ている場所の文字が「入り直し中」「探しています」に変わる。場所は取らないが、ボタンは置けない。
- **B 知らせの帯を出す**（`opt-b.png`）：上の帯の下に、戻しているものを1行ずつ出す（更新のお知らせと同じ部品）。「今すぐ試す」「やめる」「機器を選び直す」を置ける。戻ったら帯は消える。
- **C 止まったものの上に出す**（`opt-c.png`）：会議なら枠の上、音なら「音声の割り当て」の上に出す。どこが止まったかは一目で分かるが、枠の中の最後の映像が見えにくくなる。

おすすめは B。理由：押せるボタンを置ける、今ある部品を使える、枠の映像を隠さない。

**決定：B**（本人、2026-11-28）。実際の画面は `docs/design/recover/built.png`（`backhaul --demo --recover` で出せる見本表示）。上の帯の「接続中／未接続」は、入り直しの間「切断」と出す。

## 確かめ方
- 部品2つは自動テスト（Linux・Windows）。
- 機器は代役（テスト用の機器）で「抜ける → 戻る」を自動テスト。
- 会議は代役の会議部品で「回線で落ちる → 入り直す」「主催者が終える → 入り直さない」を自動テスト。
