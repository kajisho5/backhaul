# 止まらないための仕組み・その2

2026-11-28。アイデア帳の「止まらないための仕組み」の残り6個（イシュー #42〜#47）。
同日に本人が承認。**#43〜#46 はバージョン0.4.0で実装した。#47・#42 はまだ（0.5.0の予定）。**

## 実装して分かったこと（設計からの変更）
- **回線の数値（ms・%）は出せない。** Zoomの部品（7.2.5）には、遅れや取りこぼしを入れる型はあるが、それを取り出す口がなかった。出せるのは6段階の品質だけなので、上の帯は「回線 良好／注意／不良」の3段階で出す（受け取りと送りのうち悪いほう）。
- 相手ごとの「回線不安定」は、Zoomが「悪い」「とても悪い」と言ってから2秒続いたら点ける。良くなったらすぐ消す。
- ロックの解除方法は、ボタンを短く押すと2秒間「長押しで解除」と出る（常に出すと上の帯が狭くなるため）。
- 本番前チェックの「予備の音声機器」の項目は、#47 と一緒に入れる。「入力の機器」（Zoomへ音を送るPCだけ）を足した。
- 上の帯は、左側の表示（会議名・状態）が狭い画面で切れても、右側のボタン（ロック・設定）が必ず画面に残るようにした。
- Windowsの通知の状態は Windows の `SHQueryUserNotificationState` の答えで見る。これがWindows 11の「応答不可」と一致するかは実機で未確認。

## 決まり

### スリープと画面オフ（#43）
- 会議に入っている間（入り直し中も含む）だけ止める。出たら元に戻す。
- ノートPCのふたを閉じる・電源ボタンを押す、は止められない（Windowsの決まり）。スクリーンセーバーも止まらない。
- **通知は、アプリからは止められない。** Windowsの「応答不可」を切り替える公開の方法が見つからなかった。代わりに、本番前チェックで「いま通知が出る状態か」を見て知らせる。

### 本番ロック（#44）
- 上の帯の「ロック」を押すとロック中になる。解除は同じボタンを1秒長押し（押し間違いで外れないように）。パスワードは付けない。
- ロック中に押せなくなるもの：設定、役割の切り替え、会議からの退出、機器の選び直し、枠の割り当ての変更、出力の「1人1出力／2×2まとめ」。
- ロック中も押せるもの：枠ごとの音量と遅延、枠の選択、知らせの帯のボタン（今すぐ試す・元の機器に戻す）、ロックの解除。
- ロックは設定ファイルに保存しない（起動し直すと外れている）。

### 回線の品質（#45）
- 上の帯に「回線 良好／注意／不良」を出す（数値は出せなかった。上の「実装して分かったこと」）。
- 枠の「回線不安定」は、いまは見本表示でしか点かない。Zoomの部品が知らせてくる相手ごとの品質（6段階）のうち「悪い」「とても悪い」が続いたら点ける。
- 記録やグラフは付けない（本番ログ #113 の範囲）。

### 本番前チェック（#46）
- 設定の一番上に「本番前チェック」のページを足す。開いたときと「もう一度確かめる」で確かめる。**何も変更しない。**
- 項目：インターネット、ライセンス（台数・期限）、Zoomのサインイン、会議ID、音声の機器、予備の音声機器、映像の出力先（モニター）、電源とスリープ、Windowsの通知、更新。
- 結果は3段階：OK／注意（そのままでも本番はできる）／要対応（このままだと止まる）。
- 役割によって関係ない項目は出さない（映像だけのPCに音声の項目は出さない）。

### 予備の音声機器（#47）
- 音声出力の設定で「予備」を1つ選べる（選ばなければ今までどおり）。
- 主の機器が止まって**3秒**戻らなければ予備へ切り替える。割り当て（どの枠がどのch）はそのまま使う。予備のch数が足りない分は出ない。
- 主の機器が戻っても、自動では戻さない（戻すときにもう一度音が途切れるため）。知らせの帯の「元の機器に戻す」で戻す。
- 予備も止まったら、主と予備の両方を探し続ける（先に見つかったほうで出す）。
- ASIOとWindowsの音声をまたいだ予備は作らない（同じ方式の中だけ）。

### 落ちたら自動で再起動（#42）
- アプリが異常終了したら、見張り役の小さな別プロセスが立ち上げ直す。Windows標準の再起動の仕組みは「再起動しますか」と人に聞くので、無人では戻らない。そのため自前で見張る。
- 立ち上げ直したら、落ちる前に入っていた会議へ入り直す。パスコードは、会議に入っている間だけWindowsの資格情報の保管場所に置き、退出したら消す（設定ファイルには書かない）。
- 5分のあいだに3回落ちたら、立ち上げ直すのをやめる（落ち続けるのを防ぐ）。
- 固まった（応答なし）状態の検知は入れない。まずは異常終了だけ。
- オペレーターが自分で閉じたときは立ち上げ直さない。

## 技術
新しい言語・外の部品は足さない（C++20・Qt Quick・Win32 API のまま）。

- `src/core/`（自動テスト付き）：品質の段階づけ、予備へ切り替える判断、再起動の回数制限、チェック項目の判定。
- Windowsに触れる部分は `src/app/` の小さなファイルに閉じ込め、Windows以外では何もしない実装を置く（今の資格情報の保管と同じ形）。
- Zoomの統計と相手ごとの品質は `src/zoom/` の中だけで読む。
