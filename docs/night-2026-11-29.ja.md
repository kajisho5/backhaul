# 夜のあいだに作ったもの（2026-11-29、確認待ち）

本人から「寝てるから勝手にやっといて」と任された分。**設計と画面の承認はまだ**なので、本体（main）には入れず、確認待ちの申請にまとめてある。要らないものは外せる（1つずつ別の記録にしてある）。

## 1. 直し：自動更新の契約で「あと○日で期限が切れます」と出てしまう
- 見つけたこと：月額・年額の契約では、ライセンスの期限は「支払い済みの期間の終わり＋3日」。そのため、きちんと支払っている人でも、毎月の終わりの数日は本番前チェックに「あと○日で期限が切れます」と出てしまう（バージョン0.4.0で入れた項目の誤り）。
- 直し方：サーバーが「この契約は自動で更新される」とアプリに伝える。自動で更新されるあいだは、期限が近いと言わない。解約を予約したとき・支払いに失敗したとき・体験キー・手で発行したキーは、今までどおり知らせる。
- サーバーの表に列を1つ足す（`server/migrations/0004_renews.sql`）。本体に入れると、入場券サーバーが自動で更新される。
- Stripeの項目 `cancel_at_period_end`・`cancel_at` を読む（https://docs.stripe.com/api/subscriptions/object ）。
- 未確認：本物のStripeの契約での動き（自動テストは代役のStripeで通している）。設定の「○○ まで」の表示は今のまま（自動更新のときは「次の支払いの期限」の意味になる）。

## 2. 本番ログの書き出し（イシュー #114）
- 記録するもの：このPCが会議に入った・出た・回線で切れた時刻、参加者の出入り（入ったときにすでにいた人は「すでに参加していました」）、音声の機器が止まった・戻った・予備に切り替わった時刻、異常終了からの起動し直し。
- 設定の「プロジェクト」のページに「本番ログ」の欄。「CSVで書き出す」で、表計算ソフトで開けるファイルにする（時刻・できごと・名前の3列）。
- 記録はメモリーの中だけ。自分からはどこにも書かず、送らず、backhaul を閉じると消える。最大2万件（古いものから消える）。
- 参加者の名前はだれでも自由に付けられるので、表計算ソフトが「式」として実行しそうな名前（= + - @ で始まる）には、頭に ' を付けて無害にする。
- 画面：`docs/design/night/show-log-ja.png`、`show-log-en.png`。
- 未確認：回線切れから入り直した直後、Zoomが新しい参加者の一覧を返す順番（古い一覧を記録しないようにしてあるが、実機では見ていない）。Windowsの保存の窓（CSV用の種類を足した）。
